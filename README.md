# BotGhost Event Guide

Referenzprojekt für den Bau von Event-Commands und Embeds in BotGhost.
Die Inhalte stammen aus der offiziellen BotGhost-Dokumentation und liegen
kopiert in `docs/vendor/botghost/2026-10-24/Wie funktioniert das/`.

## Zweck

- Alle Bausteine des Command & Event Builders verstehen: Commands, Events,
  Embeds, Buttons, Farben, Variablen, Collections und Conditions.
- Grundlage für den Obsidian-Canvas, der den Bau des Discord-Event-Bots
  Schritt für Schritt zeigt.
- Kein Bot-Code: Gebaut wird später in BotGhost; die Anleitung liegt in
  Obsidian.

## Aufbau

- `docs/vendor/botghost/2026-10-24/Wie funktioniert das/` — kopierte
  BotGhost-Doku mit `_source.md` und `pages/`.
- `README.md` — dieser Überblick.
- `PROGRESS.md` — Stand und nächste Schritte.
